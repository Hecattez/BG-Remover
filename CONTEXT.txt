4. KEY ALGORITHM & ENGINEERING FIXES
------------------------------------
1. Split-Slider Layering:
   Cutout sits on the active backdrop; Original layer is clipped on the left
   using CSS clip-path: polygon(...) so Before/After reveals correctly.

2. Anti-Aliasing Preservation (No Jaggedness):
   post_process_mask=False in rembg.remove (prevents internal 1-bit binarization
   which caused blocky stair-stepped edges).

3. Sub-Pixel Edge Defringing:
   Continuous alpha curve (cutoff = 0.05 * trim_px) + 0.35px Gaussian feather.
   Eliminates dark shadow/background halos without jagged pixel steps.

4. Dual-Pass Saliency Fusion (fuse_dual_pass_saliency):
   Solves white-on-white / color camouflage (e.g. white shrimp meat on white background).
   Combines Color Saliency Mask and Luminance/Grayscale Saliency Mask using
   np.maximum(color_mask, gray_mask). The AI natively recognizes camouflaged
   surfaces at 100% solid opacity with no crude hole-patching.
